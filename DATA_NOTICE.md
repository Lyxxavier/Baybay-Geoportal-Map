# Project Data Notice

## Current data in this repository

The map currently uses built-in illustrative sample features from `map.js`. No official reclamation GeoJSON dataset is included or loaded.

| Item | Current information |
|---|---|
| Intended agency / provider | Philippine Reclamation Authority (PRA); intended source only, not verified as the provider of any dataset in this repository |
| Dataset name and version | No official dataset obtained or loaded |
| Date obtained | Not obtained |
| Exact dataset licence / terms | Not supplied or verified; no permission to reuse official data is asserted |

Do not treat the sample features, boundaries, areas, or dates as official. Do not publish or load real PRA data in a public deployment until the dataset source and its exact licence or written permission have been confirmed. If permission or terms are unavailable, keep the real GeoJSON private and continue using sample data publicly.

Keep any agency emails or written permissions in appropriate private records. Do not commit confidential correspondence or personal information to this repository.
